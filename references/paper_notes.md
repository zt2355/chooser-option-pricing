## 2. 论文实际做了什么（而非声称做了什么）

- 用 GBM 模拟股价路径：S_T = S₀·exp[(α − σ²/2)T + zσ√T]（式(1)，排版残缺）
- 分两段模拟：0→T₁（6个月）、T₁→T₂（6个月）
- **选择规则：在 T₁ 比较 S_T₁ 与 K**——S_T₁ > K 选 call，否则选 put（Table 3，10 条模拟）
- 对 σ、K、r、q 做了单参数敏感性分析（Fig.3–6，只有 call/put 曲线）
- 结论定性：chooser 推迟决策日、部分对冲方向风险，但不能对冲全部风险

## 3. 论文的方法论缺陷（W3/W4 报告的加分点，注意措辞客气）

1. **选择规则次优**：理性持有人在 T₁ 应比较的是**期权价值** max(C(S_T₁,τ), P(S_T₁,τ))，
   而非 moneyness（S_T₁ vs K）。两者的无差异临界点并不在 K 处（K 折现与股息调整后才是）。
   复现时应同时实现两种规则，量化"天真规则"造成的价值低估。
2. **全文没有给出一个明确的 chooser 期权价格数字**——没有解析解结果，Table 3 只有 10 条
   路径的 payoff（也未见折现和求均值）。所以"与论文结果对照"实际只能对照：
   (a) Table 3 的逐行逻辑（payoff = max(K−S,0) 或 max(S−K,0)，已验算一致）；
   (b) Fig.3–6 敏感性曲线的形状与方向。
3. 未用 Rubinstein (1991) 闭式解，未做收敛性分析，模拟次数不明。
4. "第一列 ST 来自 Yahoo"的表述与"随机模拟"自相矛盾，复现时以 GBM 模拟为准。

## 4. W3 复现方案（据此设计）

1. **闭式解**：Rubinstein (1991) simple chooser 解析定价（call(K,T₂) + put(Ke^{−r(T₂−T₁)}, T₁) 分解），用 Table 2 参数算出基准价；
2. **MC 引擎**：GBM 两段模拟，同时实现"价值最优规则"与论文"moneyness 规则"，折现均值 ± 标准误；
3. **验证**：MC(最优规则) → 收敛到闭式解（这正是 mentor 指定的 MC 验证思路）；
4. **对照论文**：复制 Table 3 格式的路径表 + 复现 Fig.3–6 四张敏感性图（方向、形状一致即复现成功）；
5. 额外：对 T₁ 做敏感性（论文自认的未竟工作，正好补上，是超预期交付点）。
